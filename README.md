# PCB-Design-Project

## Overview

This project involved designing a 7-segment digital counter printed circuit board and documenting the process from the initial circuit schematic through to PCB layout and routing.

The project allowed me to develop practical experience with PCB design and understand the workflow involved in turning a circuit schematic into a physical PCB.

## Project Workflow

The overall design process was:

1. Circuit schematic
2. Component selection
3. Footprint assignment
4. PCB schematic update
5. PCB layout
6. Component placement
7. Trace routing
8. Final PCB design

## 1. Circuit Schematic

The project began with creating the circuit schematic and connecting the required components.

![Circuit Schematic](<Image 27-08-2026 at 19.17.jpeg>)

This stage helped me understand how the electrical connections between components are represented before creating the physical PCB.

## 2. Assigning Footprints

After completing the schematic, footprints were assigned to the components.

![Footprint Assignment](images/02-footprint-assignment.png)

I learned that selecting the correct footprint is important because it determines how the physical component will be mounted onto the PCB.

## 3. Updating the PCB

Once the footprints had been assigned, the schematic was updated before transferring the design to the PCB layout.

![PCB Schematic](images/03-pcb-schematic.png)

This gave me a better understanding of how the schematic connects to the physical PCB design.

## 4. PCB Layout

The components were then positioned on the PCB.

![PCB Layout](images/04-pcb-layout.png)

I learned that component placement is important because it affects the routing of traces and the overall organisation of the PCB.

## 5. Routing

The connections between components were then routed using PCB traces.

![PCB Routing](images/05-routing.png)

This helped me understand how the electrical connections from the schematic are translated into physical copper traces on the PCB.

## 6. Final PCB

The final PCB design was then reviewed using the PCB layout and 3D view.

![Final PCB](images/06-final-3d-view.png)

## What I Learned

Through this project, I developed an understanding of the general PCB design workflow, from creating a circuit schematic through to producing a routed PCB.

Key things I learned include:

- Creating and interpreting circuit schematics
- Assigning appropriate component footprints
- Transferring a schematic into a PCB layout
- Positioning components on a PCB
- Routing electrical connections using PCB traces
- Understanding how schematic connections translate into a physical PCB
- Using PCB design software as part of an electronics design workflow
